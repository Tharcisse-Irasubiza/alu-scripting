# API advanced

Python scripts that query the Reddit API.

- `0-subs.py` - number of subscribers of a subreddit (0 if invalid)
- `1-top_ten.py` - print the titles of the first 10 hot posts (None if invalid)
- `2-recurse.py` - recursively list the titles of all hot articles (None if invalid)
- `3-count.py` - recursively print a sorted count of given keywords in hot titles
